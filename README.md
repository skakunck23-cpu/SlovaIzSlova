# Слова из слова — Android

Нативная игра на Java для Android 6.0+ без интернета, рекламы и внешних библиотек.

## Сборка APK

**В Android Studio:** File → Open → папка `SlovaIzSlova`, дождитесь синхронизации Gradle, затем Build → Build App Bundle(s) / APK(s) → Build APK(s). Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

**Через GitHub:** загрузите содержимое папки в новый репозиторий GitHub. Откройте Actions → Build Android APK → Run workflow. После завершения скачайте артефакт `SlovaIzSlova-debug-apk` и распакуйте APK.

**Из командной строки:** с установленными JDK 17, Android SDK 35 и Gradle 8.9 выполните `gradle :app:assembleDebug`.

APK debug-версии можно установить вручную на Android, разрешив установку из выбранного источника.

## Правила

Нажимайте на буквы исходного слова в нужном порядке, затем «ПРОВЕРИТЬ». Кнопка «СБРОС» очищает выбор, «ПОДСКАЗКА» открывает одно ещё не найденное слово. За слова начисляются очки. После нахождения всех предусмотренных слов открывается следующий уровень. Прогресс хранится локально.

Список допустимых слов специально ограничен набором слов для каждого уровня, а не полным словарём русского языка. Для расширения добавьте слова в массив `WORDS` в `MainActivity.java`. Слова, которые нельзя составить из букв исходного слова, автоматически исключаются.
